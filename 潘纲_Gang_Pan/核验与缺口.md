## 身份与完整性

目标是[浙江大学潘纲](https://person.zju.edu.cn/gpan/734058.html)，对应 [DBLP Gang Pan 0001，PID 86/4183-1](https://dblp.org/pid/86/4183-1.html) 与 [ORCID 0000-0002-4049-6181](https://orcid.org/0000-0002-4049-6181)。主任务取得的 DBLP 官方 SPARQL 无 LIMIT 查询、原始返回与解析基表分别保存在 `dblp/pan_gang.rq`、`dblp/pan_gang_sparql.json`、`dblp/pan_gang_papers.json`。这比限定近期顶会或少量精选更接近用户要求的全历史书目；仍不能保证覆盖所有中文期刊、未入索引新论文、书章以及跨学科出版物。

[官网论文页](https://person.zju.edu.cn/gpan/568001.html) 有中英文分栏，但本轮抓取遇验证码，没有取得可解析的完整目录。`pan_sources/dblp.xml` 及早期官网 HTML 是反机器人响应，**不是完整 XML 或有效论文表**，未参与书目解析。Crossref API 请求失败也保留了失败快照，不把失败请求当作已核验元数据。中文补充来自浙江大学学报、电子与信息学报、计算机辅助设计与图形学学报、科学通报、生命科学、《计算》和科学与社会原始出版社/机构库；中文部分仍有覆盖缺口。

曾检索到 `ucas-vg/GroupSampling`，其 TIP 2023 论文确有 Gang Pan，但[天津大学官方页](https://tiei.tju.edu.cn/info/1619/3623.htm)与其 ORCID 表明是天津同名学者，已从本资料库排除。第三方 `community-detection-code` 汇编也未冒充潘纲官方实现。`liyc5929/neuroseqbench` 同时服务多篇论文，其中有潘纲署名的时序脉冲网络综述可关联；另一篇 Neuromorphic Sequential Arena 作者没有潘纲，不自动收录为其论文。

## 强化学习、偏好优化与情感智能的边界

书目完整包含传统强化学习、时序差分、信赖域优化、安全强化学习、协作多智能体、类脑导航和离线元强化学习，未把检索局限于 EEG。例如 [APPO，AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/25888) 在安全约束优化中采用增广拉格朗日思路；[CGPO/GBE，ICML 2024](https://proceedings.mlr.press/v235/dai24d.html)针对有限时域非折扣安全约束估计；[EDRQN，IJCAI 2021](https://www.ijcai.org/proceedings/2021/66)使用熵正则生成行为多样的队友，其[代码](https://github.com/dxing-cs/EDRQN)提供训练与评估入口。这里的安全成本、环境回报和熵正则与情绪识别的分类损失属于不同对象，迁移时须重新定义任务和约束。

[TD-DPO](https://github.com/Shuzhong-Lai/TD-DPO)是针对临床自闭症干预对话迎合问题的差异感知偏好优化，适合与多模态情感智能的响应质量、用户依赖和偏好冲突议题对照。但本轮没有把它当作已有在线真人情绪调控 RL 系统。其[数据访问说明](https://github.com/Shuzhong-Lai/TD-DPO/blob/main/docs/DATA_ACCESS.md)明确不分发真实临床训练/测试对话、儿童资料、人工评分和实验输出，仓库示例为合成示例。对应 [ASD-iLLM 模型](https://huggingface.co/Shuzhong/ASD-iLLM)是 LoRA 权重；ASD-iLLM-8k 原始对话下载本轮没有定位到。

Music2Emotion 与 Tuning the Mind 的可穿戴神经反馈路线提供情绪感知与干预的连接，但不能因“闭环”“反馈”就认定使用强化学习。[ZBra 项目页](https://zju-bmi-lab.github.io/ZBra/)也不等于独立实验数据已经公开。需要沿原论文确认在线自适应机制、真人实验、主观/生理效标和策略更新方式；本资料库保留前轮核验边界，不创造 reward 公式。

## 下载与版本解释

每个资源项含 `url`、`download_url`、`access`、`author_relation`、`evidence_urls` 与 `notes`。空下载地址表示没有核得公开入口、未分发或申请制，不能自行推导文件路径。`public_link_not_downloaded` 表示作者 README 确实列出链接，本轮没有实际下载或保证网盘仍可用。源数据、预处理划分、标注、模型权重、项目网页和代码集合分别标类型。

前轮 19 篇数据审计的 **64 个独立条目与 140 次使用映射**已复用在资源对象的 `paper_usage`，明确区分主论文实验、附录实验和仓库额外 loader。TUH 采用当前签表申请后 SSH keys + rsync 的官方流程；SHU-MI 使用原始 Figshare 完整档案并按要求邮件索取压缩包密码，不能把 Harvard 仅一个文件的快照称作全库；MASS-EX 只补充标注，原始 MASS PSG 另申请；医院自采数据按私有/申请记录。没有下载大数据或权重，也没有代用户发送申请邮件。

日期保留原始出处：MindGPT 的 arXiv 2023 与 TIP 2025 是不同版本；Brain-CLIPLM 预印本题名与 2026 Frontiers 正式题名不同；DOCTer-G 在线日期与最终 PDF ©2027 分开；COINR 的 Pattern Recognition 卷年为 2027，不能只根据 DOI 中的 2026 改成 2026 正式发表。IROS 导出单条年份为空，已据 IROS 2023 会议目录补 2023，并保留原始 SPARQL 快照。

## 仍未覆盖的部分

482 条书目不意味着每篇都已取得完整代码和全部实验数据。大多数历史论文仍只有可核元数据和出版链接，未核到资源的条目在 `resource_status` 写明；这不能推导为作者从未发布资源。完整官网中文列表、早期网页失效资源、受许可保护数据、个别新论文正式卷期与完整项目运行验证仍是缺口。所有主题分类仅用于检索，不是全文级方法审计或质量评分。

`build_pan_gang.py` 可重建当前资料库；后续若主任务加入全量中文辅助译名，避免直接覆盖这些增补字段。数据库完整性检查应核对 465 个 DBLP key 无遗漏、资源 ID 无悬空、作者表非空及同名排除记录。


论文数据只做书目与资源核验，未执行代码训练、未批量下载全文/权重/原始数据。作者数据库和个人主页均可能漏收；不能保证覆盖所有中文论文、临床合作论文、最新预印本、专利和专著。未做逐篇全文质量评分，避免把目录覆盖量误作证据强度。
